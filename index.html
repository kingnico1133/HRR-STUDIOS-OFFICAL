The current project

VOID BREACH:
LITE

VOID BREACH is a top-down arcade survival game. Enemies come in from around the arena, waves build on each other, and power-ups can help you stay alive a little longer.

The Lite build is a small browser-playable preview. It's here so you can try the game for yourself, not just read about it.
