FIREBASE:
The rating panel uses Anonymous Authentication and Cloud Firestore.
Before ratings can save, deploy the new firestore.rules file to the existing Firebase project.

From the already-initialized Firebase folder on the Mac:
1. Replace the contents of its firestore.rules with the firestore.rules file from this update.
2. In Terminal, run:
   firebase deploy --only firestore:rules

No Firebase Hosting setup is needed. Keep the existing website hosting as it is.

PRIVACY / DATA:
Each anonymous Firebase user has one vote document. It contains only:
- vote: like or dislike
- reasons: up to three prewritten reason selections

Vote documents are publicly readable so the page can calculate totals. No comments or personal profile data are collected. Anonymous identities are browser-based and are not strong anti-abuse protection.
